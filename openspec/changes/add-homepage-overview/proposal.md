# Change: 首页改为系统状态总览

## Why

首页目前是脚手架模板留下的假内容：三张写死的数字卡（用户总数 1024 / 文档数量 256 / 待办通知 8）、一句「Vue3 + Element Plus 前端脚手架已就绪」、一个「测试后端接口连通性」按钮。**没有一个数字是真的**，也没有任何本系统的信息。

使用者打开系统第一眼看到的应当是**自己关心的事**：接进来的库有没有问题、知识库的文档摄进去了没有、以及**为什么某个功能用不了**（模型没配）。

## What Changes

- 新增能力 `system-overview` 与模块 `src/apps/overview/`（无数据模型）
- 新增聚合接口 `GET {SYS_NAME}/v1/overview`，一次返回首页所需的全部数据
- 首页改为**状态总览**，左右两栏呈现系统里仅有的两条有数据沉淀的能力线：
  - 左栏「已纳管的库」：每库一行，显示表数与问题分级（取最新快照）、采集状态与下一步动作
  - 右栏「知识库」：每个知识库一行，显示文档数与摄入状态（有失败时标出并可查看原因）
- 顶部**系统就绪提示**：对话模型 / 嵌入模型是否已配置；缺失时说明影响哪些功能并给出配置入口
- 空状态给出引导（还没有接入数据库 / 还没有知识库）
- 明确**不做**：向量服务探测、SQL 分析的任何数据（它不落库）、图表（无历史序列数据）

## Impact

- 受影响能力：**新增** `system-overview`；不改动任何现有能力的既有需求
- 受影响代码：
  - `src/apps/overview/`（**新增模块**：`views.py` / `serializers.py` / `services.py`，无模型）
  - `src/config/urls.py`（注册路由）
  - `static/src/views/home/index.vue`（**整体重写**，替换脚手架假内容）
  - `static/src/api/overview.js`（**新增**）
- 跨模块只读：数据分别取自 `datasource.services` / `knowledge` 两个模块已声明的服务函数与查询，不直接跨模块查其 model
- 无数据表变更，无需 SQL 补丁
