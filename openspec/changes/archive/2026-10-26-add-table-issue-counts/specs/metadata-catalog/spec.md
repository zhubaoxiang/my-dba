## ADDED Requirements

### Requirement: 表清单问题数

库表分析的表清单 SHALL 为每张表返回按严重级别汇总的问题数量，包含高风险、中风险、低风险与总数。统计 MUST 基于最近一次快照，MUST 排除已静音问题，MUST 与问题清单、问题统计保持同一口径。

#### Scenario: 表清单展示问题数

- **WHEN** 用户打开库表分析页
- **THEN** 每张表 MUST 显示高风险、中风险、低风险问题数量
- **AND** 没有问题的表 MUST 显示为空计数，而不是省略该列

#### Scenario: 静音问题不计入

- **WHEN** 某条问题已被静音
- **THEN** 该问题 MUST NOT 计入对应表的问题数
- **AND** 问题清单与问题统计 MUST 同步排除

#### Scenario: 按表定位

- **WHEN** 用户查看某张表所在行
- **THEN** 显示的问题数 MUST 只统计该模式下的该表，MUST NOT 混入同名表或其他模式的问题

#### Scenario: 按问题数排序

- **WHEN** 表清单返回
- **THEN** 表 MUST 按高风险问题数降序排列
- **AND** 高风险数相同时按中风险数降序
- **AND** 中风险数相同时按低风险数降序
- **AND** 各级别都相同时按模式名与表名排序，保证分页顺序稳定

### Requirement: 表清单问题下钻

表清单 SHALL 在操作列提供「详情」与「问题」两个操作。点击「详情」打开当前表详情；点击「问题」跳转到问题清单，并携带数据源、模式与表名条件。问题清单接口 MUST 支持按模式与表名过滤，页面 MUST 展示当前表条件并允许清除。

#### Scenario: 点击详情

- **WHEN** 用户点击某行的「详情」按钮
- **THEN** 系统 MUST 打开该表的详情
- **AND** 仅点击行本身 MUST NOT 打开详情

#### Scenario: 点击问题跳转

- **WHEN** 用户点击某行的「问题」按钮
- **THEN** 系统 MUST 跳转到问题清单
- **AND** MUST 携带该行的数据源、模式与表名作为过滤条件
- **AND** 问题清单 MUST 只展示该表的已过滤结果

#### Scenario: 条件可见且可清除

- **WHEN** 问题清单带有表过滤条件
- **THEN** 页面 MUST 展示当前表条件
- **AND** 用户清除条件后 MUST 恢复为该数据源的全部问题
- **AND** 切换数据源时 MUST 清除上一个数据源的表条件

#### Scenario: 同名表不混淆

- **WHEN** 不同模式下存在同名表
- **THEN** 跳转 MUST 同时携带模式名
- **AND** 问题清单 MUST 只返回该模式下的表的问题
