## MODIFIED Requirements

### Requirement: 库表健康问题分析

系统 SHALL 基于快照产出健康问题清单，至少覆盖：无主键表、外键缺索引、重复或冗余索引、疑似未使用索引、超大表（行数或体积超阈值）、可疑字段类型、孤立表（无关联）、**金额类字段使用浮点类型**、**主键使用长字符类型**、**宽表（列数超阈值）**、**索引体积超过数据体积**。参与分析的规则 MUST 取自规则注册表中处于启用状态的规则；被停用的规则 MUST NOT 产出新问题。每条问题 MUST 包含严重级别、规则标识与名称、适用层级、对象定位（模式.表.列）、问题说明与改进建议。

#### Scenario: 识别无主键表

- **WHEN** 快照中存在没有主键的表
- **THEN** 问题清单中生成一条对应问题，包含严重级别与表定位

#### Scenario: 识别外键缺索引

- **WHEN** 快照中某外键列没有以该列为前导列的索引
- **THEN** 问题清单中生成一条对应问题，包含表、列与外键约束名

#### Scenario: 识别重复或冗余索引

- **WHEN** 同一张表上存在列组合完全相同或构成前缀包含关系的多个索引
- **THEN** 问题清单中生成一条对应问题，标明可保留与可删除的索引名

#### Scenario: 识别超大表

- **WHEN** 某表的行数或占用空间超过该规则配置的阈值
- **THEN** 问题清单中生成一条对应问题，包含实际数值与所用阈值

#### Scenario: 识别可疑字段类型

- **WHEN** 表中存在用字符类型存储时间、超长 varchar 或大对象字段
- **THEN** 问题清单中生成一条对应问题，标明字段与不推荐的类型

#### Scenario: 识别浮点类型的金额字段

- **WHEN** 某列的**类型是浮点**（`real` / `double precision` / `float` 等）**且列名或注释含金额语义**
- **THEN** 问题清单中生成一条对应问题，标明该列与浮点类型会丢失精度
- **AND** MUST NOT 对**所有**浮点列产出该问题——浮点在科学计算等场景下是正确选择

#### Scenario: 识别长字符类型的主键

- **WHEN** 主键列使用字符类型，且其长度无界或超过该规则配置的阈值
- **THEN** 问题清单中生成一条对应问题，包含表、主键列与实际长度

#### Scenario: 识别宽表

- **WHEN** 某表的列数超过该规则配置的阈值
- **THEN** 问题清单中生成一条对应问题，包含实际列数与所用阈值

#### Scenario: 识别索引体积超过数据体积的表

- **WHEN** 某表的索引占用**大于**其数据占用，且该表有数据
- **THEN** 问题清单中生成一条对应问题，包含两侧的实际体积

#### Scenario: 问题携带规则标识与层级

- **WHEN** 任一规则产出问题
- **THEN** 该问题带有规则 `code`、规则名称与适用层级，可按问题类型筛选

#### Scenario: 停用的规则不产出新问题

- **WHEN** 某条规则在规则注册表中被停用后再执行分析
- **THEN** 该规则不产出任何新问题，其余规则照常产出

#### Scenario: 规则集变化可被察觉

- **WHEN** 查询某次分析的总览统计
- **THEN** 统计中包含本次实际参与评估的规则数量，便于与启用规则总数比对

#### Scenario: 无问题时返回空清单

- **WHEN** 快照中不存在任何已启用的规则所描述的问题
- **THEN** 问题清单返回空列表而非报错
