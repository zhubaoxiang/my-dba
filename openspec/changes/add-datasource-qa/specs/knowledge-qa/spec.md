## ADDED Requirements

### Requirement: 数据源范围问答

系统 SHALL 允许提问时指定一个已纳管数据源，并在该数据源的最近一次元数据快照范围内回答表数量、表结构与健康问题。数据源 MUST 作为可选上下文与知识库并存，MUST NOT 连接被纳管数据库执行实时查询。

#### Scenario: 选择数据源后询问表数量

- **WHEN** 用户选择某数据源并提问「这个环境有多少张表」
- **THEN** agent MUST 调用数据源概况工具，并基于最新快照给出表数量
- **AND** MUST NOT 根据模型自身记忆编造数量

#### Scenario: 同时选择知识库和数据源

- **WHEN** 用户同时选择知识库与数据源，提问同时涉及文档知识与环境事实
- **THEN** agent MAY 在同一次回答中调用知识库检索与数据源工具，并综合结果

#### Scenario: 知识库无命中但已选数据源

- **WHEN** 自动模式下知识库检索无命中，且本次提问指定了数据源
- **THEN** 系统 MUST 进入 agent 并调用数据源工具作答
- **AND** MUST NOT 直接回退到通用模型

#### Scenario: 只选数据源

- **WHEN** 用户只选择数据源、不选择知识库
- **THEN** 系统 MUST 直接进入 agent，使用数据源工具作答
- **AND** MUST NOT 因缺少知识库而跳过数据源

#### Scenario: 未指定数据源

- **WHEN** 提问未指定数据源
- **THEN** 系统行为 MUST 与既有问答一致，MUST NOT 构造数据源工具

#### Scenario: 仅知识库模式

- **WHEN** 回答模式为「仅知识库」且指定了数据源
- **THEN** 系统 MUST NOT 调用任何数据源工具
- **AND** MUST 只依据知识库作答

#### Scenario: 数据源不存在或未采集

- **WHEN** 提问指定的数据源不存在或已软删除
- **THEN** 系统 MUST 返回明确的配置错误，提示重新选择数据源
- **WHEN** 数据源存在但尚未采集
- **THEN** 工具 MUST 如实告知尚未采集，MUST NOT 编造表或问题

### Requirement: 数据源诊断工具

系统 SHALL 为 agent 提供数据源概况与问题清单工具。概况 MUST 包含表数量、模式数量、问题总数与严重级别分布、最近采集时间；问题清单 MUST 支持按表名和严重级别过滤，MUST 排除已静音的问题，并 MUST 限制返回条数与单条文本长度。

#### Scenario: 查看整体概况

- **WHEN** agent 调用数据源概况工具
- **THEN** 返回表数量、模式数量、各级别问题数量、问题总数与最近采集时间

#### Scenario: 查看问题清单

- **WHEN** 用户提问「哪些表有明显问题」
- **THEN** agent MUST 调用问题清单工具，并基于返回的问题与表定位作答
- **AND** 回答 MUST NOT 出现工具未返回的表或问题

#### Scenario: 按表名与级别过滤

- **WHEN** 用户追问某张表或某个严重级别的问题
- **THEN** agent MAY 以表名或级别作为参数再次调用问题清单工具

#### Scenario: 静音问题不参与回答

- **WHEN** 某条问题已被静音
- **THEN** 问题清单与统计 MUST 排除该问题，与现有问题清单、首页统计保持同一口径

#### Scenario: 输出受控

- **WHEN** 问题数量很多
- **THEN** 工具 MUST 只返回有限条数并截断单条说明，避免一次返回撑满模型上下文

#### Scenario: 记录实际调用的工具

- **WHEN** agent 在回答中调用了数据源概况、问题清单或表结构工具
- **THEN** 回答的 `tools_used` MUST 包含这些工具名，供使用者判断回答依据

### Requirement: 数据源问答界面

系统 SHALL 在问答页面提供数据源选择，与知识库选择、回答模式并列。选中的数据源 MUST 随提问提交，会话 MUST 持久化该选择并在重新打开时恢复；清除选择后 MUST NOT 继续使用旧数据源。

#### Scenario: 选择数据源并提问

- **WHEN** 用户在问答页面选择数据源后提问
- **THEN** 请求 MUST 携带该数据源的标识

#### Scenario: 重新打开会话恢复选择

- **WHEN** 用户重新打开一个曾指定数据源的会话
- **THEN** 页面 MUST 恢复该会话的数据源选择

#### Scenario: 清除数据源选择

- **WHEN** 用户清除数据源选择后继续提问
- **THEN** 本次提问 MUST NOT 使用该会话此前选中的数据源
- **AND** 后续提问 MUST 同样保持未指定状态

#### Scenario: 停用数据源可见

- **WHEN** 数据源已停用但仍存在
- **THEN** 选择列表 MAY 展示该数据源并标明停用状态，MUST NOT 静默隐藏
